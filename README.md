One pickup line, 180 characters, that a vending machine would use on a passing human — entered in make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty ($2 over 10 paid places). The machine introduces itself from its corner, admits it hums for a hundred strangers a day, then singles the passer-by out: its coils only ever tremble for them. Press B7 and it drops the good stuff — and, flirting hardest where a vending machine never bends, exact change is not required.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (UTF-8, one line, 1–200 characters, no trailing newline). Pure Python standard library, no network, no secrets.
